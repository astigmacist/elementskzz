# 📤 Как отправить проект другу

## Шаг 1: Создать репозиторий на GitHub

### А) Зарегистрироваться на GitHub (если нет аккаунта)
1. Зайти на https://github.com
2. Нажать **Sign up** (Регистрация)
3. Ввести email, пароль, username

### Б) Создать новый репозиторий
1. Войти в GitHub
2. Нажать кнопку **"+"** вверху справа → **"New repository"**
3. Заполнить:
   - **Repository name:** `elementskz`
   - **Description:** "Elements KZ - интернет-магазин электроники"
   - **Visibility:** 
     - ✅ **Private** (только вы и друг) 
     - ❌ Public (весь интернет увидит)
4. **НЕ** ставить галочки:
   - ❌ Add a README file
   - ❌ Add .gitignore
   - ❌ Choose a license
5. Нажать **"Create repository"**

---

## Шаг 2: Отправить код на GitHub

После создания репозитория GitHub покажет инструкции. **Скопируйте URL** который выглядит так:

```
https://github.com/ВАШ-USERNAME/elementskz.git
```

### Откройте терминал и выполните:

```bash
# Перейти в папку проекта
cd /Users/erbolsadibekov/Desktop/elementskz

# Подключить GitHub репозиторий (ЗАМЕНИТЕ URL на свой!)
git remote add origin https://github.com/ВАШ-USERNAME/elementskz.git

# Отправить код на GitHub
git push -u origin main
```

**Готово!** 🎉 Код теперь на GitHub!

## Шаг 3: Добавить друга в репозиторий

### Дать другу доступ к приватному репозиторию:

1. Зайти в ваш репозиторий на GitHub
2. Нажать **Settings** (вкладка вверху)
3. В левом меню выбрать **Collaborators**
4. Нажать **"Add people"**
5. Ввести **username** или **email** вашего друга
6. Нажать **"Add [username] to this repository"**
7. Друг получит приглашение на email

---

## 🔄 Как обновлять код на GitHub в будущем

### Каждый раз когда сделали изменения:

```bash

# 2. Добавить изменения
```

## 🆘 Если возникли проблемы

### "Permission denied" при git push:
Нужно настроить авторизацию GitHub. Два варианта:

**А) Через Personal Access Token:**
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token → Выбрать все галочки → Generate
3. **СКОПИРОВАТЬ ТОКЕН** (больше не покажут!)
4. При `git push` ввести:
   - Username: ваш username
   - Password: **ваш токен** (не пароль!)

**Б) Через SSH (посложнее):**
1. Сгенерировать SSH ключ:
```bash
ssh-keygen -t ed25519 -C "your@email.com"
# Нажать Enter 3 раза
```
2. Скопировать ключ:
```bash
cat ~/.ssh/id_ed25519.pub
```
3. GitHub → Settings → SSH and GPG keys → New SSH key → Вставить
