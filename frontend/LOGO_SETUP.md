# 🎨 Установка логотипа Elements KZ

## Шаг 1: Конвертация логотипа в PNG

У вас есть логотип с радужными цветами (градиент). Нужно сохранить его как PNG.

### Способ 1: Онлайн конвертер
1. Откройте https://convertio.co/ru/
2. Загрузите ваш логотип
3. Выберите формат PNG
4. Скачайте результат

### Способ 2: Photoshop/GIMP
1. Откройте логотип
2. File → Export As → PNG
3. Сохраните с прозрачным фоном

### Способ 3: macOS Preview
1. Откройте логотип в Preview
2. File → Export
3. Format: PNG
4. Save

## Шаг 2: Добавление логотипа в проект

Сохраните PNG файл как:
```
/Users/erbolsadibekov/Desktop/elementskz/frontend/public/logo.png
```

### Рекомендуемые размеры:
- **Ширина:** 200-300px
- **Высота:** 200-300px
- **Формат:** PNG с прозрачным фоном
- **Вес:** до 100KB

## Шаг 3: Проверка

После добавления логотипа:
1. Перезапустите Next.js (если нужно)
2. Откройте http://localhost:3001
3. Логотип должен появиться в header
